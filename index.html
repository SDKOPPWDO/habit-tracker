GitHub 同步

把習慣資料以 JSON 儲存到你自己的 GitHub repo。需要一組對該 repo 有「Contents 讀寫」權限的 Personal Access Token。

• Token 只存在你這台裝置的瀏覽器，不會傳給任何第三方。
• 在 Claude 預覽視窗中，瀏覽器沙盒會擋掉對外網路，同步會失敗——把此頁放到你的 GitHub Pages 或用本機瀏覽器開啟即可正常運作。
• 建議使用 fine-grained token，只授權這一個 repo 的 Contents 讀寫。
